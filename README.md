# Navidrome 同步

独立的 Songloft 插件，将 Navidrome 收藏和选定歌单持续同步为普通 Songloft 歌单。连接、认证、播放解析和后台任务均由本插件负责，无需安装 Subsonic 或 MIoT 插件。使用 Navidrome 的 Subsonic 兼容 API。

[English](README.en.md)

## 配置与使用

1. 在 Songloft 上传 `dist/navidrome.jsplugin.zip`，打开插件页面。
2. 输入连接名称、Navidrome 基础地址、用户名和密码。支持反向代理子路径，不要附加 `/rest`。测试并保存连接。
3. 勾选收藏和歌单，按需设置目标名称；留空时跟随「连接名 · 远端歌单名」。可先预览，再保存并同步。
4. 按需启用自动同步，间隔 5～10080 分钟，默认 30 分钟。启用时会保留其他常驻插件设置，并把 `navidrome` 加入主程序常驻列表。关闭自动同步不自动移除常驻项，以免影响其他连接。
5. 在主程序歌单中播放；音箱可复用这些普通歌单，专用语音口令不在本插件范围内。

页面直接使用宿主注入的 `theme.css`、`components.css` 和 `SongloftPlugin` 客户端 API。字体、颜色、按钮、输入框、开关、卡片及明暗主题跟随主程序。桌面采用双栏，移动端为单栏，不复制宿主样式。

## 宿主兼容

**必须使用包含 songloft-org/songloft#558 宿主改动的构建。** 现有正式版 2.13.9 不包含 `playlists.replaceSongs` 和 `songs.create(..., {probeMetadata: false})`。插件会检测原子接口；旧宿主可以配置及测试连接，但不能同步，不会降级为分步清空和重建。

清单将最低宿主版本标为 `2.13.10`，该版本是本接口预计进入的下一正式版；本次没有发布宿主正式版。该字段是兼容提示，不能代替运行时检查；开发版宿主包含接口时可使用。

## 同步语义

- 单向同步：Navidrome 决定受管理歌单的成员及顺序；Songloft 中的手动成员修改会被下次同步覆盖。
- 收藏按收藏时间降序、歌曲 ID 升序固定排列。普通歌单保留远端顺序；Songloft 的成员唯一约束使远端重复歌曲只保留首次出现。
- 固定连接 ID + 远端歌曲/歌单 ID 标识来源，不按名称匹配。一个连接内跨歌单复用歌曲记录；不同连接隔离。更换服务器或账号须新建连接。
- 完整拉取及校验远端后才更改目标成员；远端失败、无效响应、缺失歌曲信息不清空歌单。成功返回的空列表会清空。成员和顺序在同一数据库事务内替换，失败回滚。
- 每个歌单独立成功/失败，页面记录最近尝试、最近全部成功、每个歌单的最近成功、增删数量和错误。
- 重复同步、插件重启复用原歌单；创建成功但映射未保存时可按描述中的来源标记恢复。用户删除目标歌单后，下次同步重新创建。来源标记被修改则停止更新，避免覆盖其他用途的歌单。
- 暂停、取消勾选、移除连接或远端歌单被删除均保留本地歌单和全局歌曲记录。移除连接后该连接的远程歌曲无法再解析播放，页面会明确提示。
- 同步任务和配置写入串行，冲突返回 409；每 30 秒检查到期任务，重启后带 3～10 秒随机延迟恢复。失败退避，最长 6 小时或用户更长的间隔。
- 同步导入标题、艺术家、专辑名及封面/歌词引用，明确关闭宿主自动音频探测，不获取音频文件。播放时按原始歌曲 ID 解析地址，不重新搜索其他平台。
- 封面按 Navidrome 的 `coverArt` ID 在服务端获取；歌词按原始歌曲 ID 通过 `getLyricsBySongId` 读取，支持内嵌纯文本和同步歌词，优先选择有效的同步歌词并应用毫秒偏移。需要 Navidrome 提供该歌词 API；不会按歌名搜索替代歌曲。Navidrome 未返回的专辑名或封面不会自行推测。
- 更新插件后执行一次「立即同步」，即可给原有远程歌曲补齐引用并刷新专辑名，无需删除歌单或重新导入；歌曲和歌单 ID 保持不变。封面和歌词在查看时按需获取，获取失败不改变已同步成员。
- 认证信息保存在服务端插件 storage 中，不回显密码；歌曲仅保存来源 ID 和不含凭证的插件内部媒体路径。封面使用 `fs` 权限写入插件自己的数据目录，并由宿主返回原始图片字节，不向客户端重定向带认证参数的 URL。相同封面复用文件，后续获取原子替换；卸载行为遵循宿主 storage 生命周期。不要手工公开插件数据目录。

首期最多 20 个连接、每个连接 200 个同步目标。Navidrome 应返回有效音频时长；时长缺失或视频内容将使对应歌单同步失败并保留原成员。

## 开发与验证

```bash
npm ci
npm run typecheck
npm test
npm run build
npm run validate
npm run check:format
```

基于 `npx create-songloft-plugin@latest` 的 Vanilla + static 模板。`npm run validate` 校验构建后的清单，产物为 `.jsplugin.zip`（含 QuickJS 字节码）。发布版 SDK 尚未包含新接口类型，`sync.ts` 中暂时为这两处添加兼容类型，宿主实现和正式 SDK 类型在主仓库/toolchain 中同步维护。

行为测试使用可控 Navidrome 响应和宿主接口；真实 QuickJS/SQLite/浏览器验证边界及截图见 [验证记录](VERIFICATION.md)。真实 Navidrome 账号、原生设备与音箱实测另行验收。

内嵌歌词、专辑及封面修复已用隔离的真实 Navidrome 0.64.2 和合成 FLAC 验证，含旧插件升级、原记录补齐和宿主重启；详见 [元数据验证记录](docs/metadata-558.md)。报告人的服务版本、私人曲库及原生客户端仍待验收。
